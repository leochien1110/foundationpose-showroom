# Soda-can example

`coke_can.glb` is the original textured scan used for the RealSense D435 evaluation. It is a 100,000-triangle mesh with an embedded texture. The dashboard scales it to the measured physical height of **145 mm** along the **Y axis** and converts it to FoundationPose-compatible PLY as needed.

Select **Coke can scan** in the dashboard to use it directly. For the single-can RGB-D demo, place an upright red-labeled Coke can about 0.4–0.6 m from the camera, with the whole can in view. Use text-prompted YOLOE with `soda can` to try multiple cans of the same size and shape.
