Detection and pose settings

Enter one object name. A new prompt builds a TensorRT engine on first use. Repeat prompts reuse the cached engine.

Pose runtime and pose updates apply when selected. Leave the exact count blank to register every usable detection up to the object limit. The selected mesh applies to each instance.

Preload warms up detection, registration, and tracking. If Exact count is set, it determines how many objects to prepare. Otherwise, leave Preload objects blank to use the latest valid detection count, or one object if none is available. Set a capacity to avoid rebuilding when the scene has up to that many objects.
